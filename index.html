Block the shot in 3D, then generate it

Free, open source previs in your browser. Stage the scene, pose characters, set the camera and cuts, then hand the same shot to an AI video model.

Why

A text prompt cannot hold a whole scene

AI video costs money per take, and one miss means paying again.

Make those decisions first, in 3D, where they are cheap to change. The video model then gets the shot as a first frame, a greybox reference clip and a prompt that describes the real framing. It follows the blocking instead of guessing.

How it works

Stage, move, shoot, export

One local workspace that handles like a 3D editor, from the empty deck to the files a video model reads.

Step 1

Stage

Build the set from primitives. Add rigged characters, or capsule stand-ins.

Step 2

Move

Describe the action. The compiler bakes every frame; QA checks collisions, foot slide and reach.

Step 3

Shoot

Shots on a timeline, dolly rails and cranes, a look through the lens.

Step 4

Export

Everything the video model needs, in one pack. Every edit is one undo step.

  • Keyframe packFirst and last frame, greybox clip, camera, prompt
  • VideoThe shot as an mp4
  • PassesDepth and normal
  • Contact sheetThe shots side by side
  • OTIO cut listThe edit, for your editing software
  • StoryboardPanels with captions and an animatic
Direct it with AI

Your agent builds the scene while you watch

The same scene can be driven from three places, live in the viewport. Bring ChatGPT, Anthropic, OpenAI, Gemini, MiniMax, OpenRouter or CLIProxyAPI.

Agent panel

Chat beside the viewport and watch each change land. Sign in with ChatGPT or use your own key. Every change the agent makes is one undo step.

MCP server

Add CozyClay to Claude Desktop, Claude Code, Cursor or any MCP client. The agent edits the scene in the studio you have open.

  }
}

Quick start

One command

Node.js 22.19+ and a Chromium browser. The studio opens at 127.0.0.1:5180/app/.

npx cozyclay --via site
git clone https://github.com/HaD0Yun/CozyClay.git
cd CozyClay
npm install
npm run dev

Install CozyClay

The installed Studio adds the AI agent, which builds scenes and motion from your words. Free, and it runs on your computer.

  1. Install Node.js

    CozyClay runs on Node.js 22.19 or newer. Open the downloaded file and click through the installer. Already have it? Skip this step.

    Download Node.js

  2. Open Terminal

    Press ⌘ Space, type Terminal, then press Return.

  3. Paste this and press Enter

    The first time, it asks to install cozyclay: type y. The Studio then opens in your browser. Run the same command to open it again.

    npx cozyclay --via site
